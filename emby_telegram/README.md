# Emby → Telegram Pipeline

GUI מקצועי שמתחבר ל-Emby, מאפשר לבחור ספריות/סדרות/סרטים/פרקים,
ועובד אחד-אחד: הורדה → העלאה לטלגרם → מחיקת הקובץ → הבא.

## תכונות

**הורדה והעלאה:**
- 🔓 עוקף `EnableContentDownloading=False` דרך PlaybackInfo
- ☁️ עוקף Cloudflare TLS fingerprint עם `cloudscraper`
- 📤 שלושה מצבי העלאה: Bot (50MB), חשבון משתמש (2GB / 4GB Premium), או **מקומי בלי טלגרם**
- 📝 הורדת כתוביות חיצוניות אוטומטית (srt/vtt/ass/ssa)
- ✂️ פיצול אוטומטי לקבצים מעל המגבלה
- 🚫 דילוג חכם על קבצים גדולים מדי (אם פיצול כבוי)
- 🔁 חזרה אוטומטית על ניסיונות שנכשלו (מספר + השהיה ניתנים להגדרה)

**UI/UX:**
- 🎨 ערכת clam מודרנית, RTL מלא בעברית עם python-bidi
- 🏷️ אייקונים על כל לשונית: ⚙ 🔎 📥 📜 📋
- 📊 פס פרוגרס כללי + ETA אוטומטי
- 🟢🔵🟠🔴⚪ שורות תור צבועות לפי סטטוס: הושלם / פעיל / דילוג / שגיאה / ממתין
- 🔍 סינון חי של התור לפי שם
- 🖱️ תפריט מקש ימני בתור: הסר / נסה שוב
- ⌨️ קיצורי מקלדת: Ctrl+Enter (התחל), Ctrl+. (עצור), Ctrl+F (חיפוש), F5 (התחבר), Ctrl+S (שמור), Ctrl+Q (יציאה)
- 📜 לשונית היסטוריה — 500 פריטים אחרונים נשמרים בקונפיג, עם תאריך, משך, תוצאה
- 💾 שמירת גודל החלון בין הפעלות
- 🏠 Header bar עם מצב חיבור והודעה מנחה
- ⚠️ אישור לפעולות הרסניות (נקה תור, נקה היסטוריה)

## הגדרה ראשונית

### 1. פרטי Telegram
- API ID + API Hash מ-https://my.telegram.org → API Development Tools
- בחר מצב:
  - **חשבון משתמש**: צריך מספר טלפון (לוגין ראשון יבקש קוד באפליקציה). עד 2GB / 4GB Premium.
  - **בוט**: צריך Bot Token מ-@BotFather. עד 50MB בלבד.
  - **מקומי**: לא צריך כלום מטלגרם. הורדה לדיסק בלבד.
- Chat ID: `me` ל-Saved Messages, `@user`, או `-100xxx` לערוץ

### 2. פרטי Emby
- URL, שם משתמש, סיסמה

### 3. אוטומציה (אופציונלי)
- **מגבלת גודל (MB)**: 0 = ללא. ברירות מומלצות: 50 לבוט, 1900 למשתמש, 3900 ל-Premium
- **פיצול אוטומטי**: אם קובץ עובר את המגבלה, מפצל לחלקים במקום לדלג
- **ניסיונות חוזרים**: בכשל זמני (רשת/שגיאת טלגרם), נסה שוב X פעמים עם השהיה של Y שניות

### 4. תיקיית הורדה
- ברירת מחדל: `~/.emby_telegram_pipeline/downloads`
- ה-checkbox "מחק קובץ מהדיסק" מאפשר לשמור עותק מקומי גם אחרי העלאה מוצלחת

## תהליך מלא לפריט

```
PlaybackInfo  →  קישור הורדה + כתוביות
    ↓
הורדה לתיקייה  →  עדכון פרוגרס בלייב
    ↓ (בדיקת גודל)
[קובץ > מגבלה]
   ┌─ אם פיצול אוטומטי → לפצל לחלקים → להעלות כל אחד עם caption "X חלק K/N"
   └─ אחרת → דילוג (status: דילוג, מקטלג בהיסטוריה)
[קובץ ≤ מגבלה] → להעלות רגיל
    ↓
מחיקה (אם מסומן)
    ↓
לכתוביות (אם יש): הורדה → העלאה → מחיקה
    ↓
היסטוריה ← רישום הצלחה / כשלון / דילוג
    ↓
פריט הבא בתור
```

## קיצורי מקלדת

| מקש | פעולה |
|-----|--------|
| Ctrl+Enter | התחל worker |
| Ctrl+. | עצור worker |
| Ctrl+F | מעבר לחיפוש |
| F5 | התחבר ל-Emby |
| Ctrl+S | שמור הגדרות |
| Ctrl+Q | סגור אפליקציה |

## פתרון בעיות

| הודעה | משמעות |
|--------|--------|
| "Your account has been disabled" | האדמין השבית את חשבונך ב-Emby |
| "PlaybackInfo החזיר שגיאה" | טוקן פג, התחבר מחדש |
| "FILE_TOO_BIG" | קובץ עולה על מגבלת טלגרם — הפעל פיצול אוטומטי או הקטן מגבלה |
| "FLOOD_WAIT_X" | Telegram מגביל - הסקריפט יחכה ויחזור אוטומטית |
| 403 / blocked | Cloudflare TLS — וודא ש-cloudscraper מותקן |
