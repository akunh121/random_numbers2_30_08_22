# Emby → Telegram Pipeline

אפליקציית GUI שמתחברת ל-Emby, מאפשרת לבחור ספריות/סדרות/סרטים, ואז
מורידה כל פריט, מעלה לטלגרם, מוחקת מהדיסק, ועוברת לבא בתור.

## תכונות

- 🖱️ GUI ויזואלי (tkinter, בלי תלויות חיצוניות)
- 🔍 דפדוף בכל הספריות והסדרות + חיפוש לפי שם
- ☁️ עוקף Cloudflare TLS fingerprint עם `cloudscraper`
- 🔓 משתמש ב-PlaybackInfo במקום `/Download` — עובד גם כש-EnableContentDownloading=False
- 📤 העלאה דרך Pyrogram: חשבון משתמש (עד 2GB/4GB) או בוט (עד 50MB)
- 🗑️ מחיקת קובץ אחרי העלאה מוצלחת
- 📊 פרוגרסים בזמן אמת + לוג

## התקנה

```bash
pip install -r requirements.txt
python app.py
```

לא נדרשת התקנה של חבילות גרפיות נוספות — tkinter מגיע עם פייתון.

## הגדרה ראשונית

1. **API ID + API Hash מטלגרם:**
   - היכנס ל-https://my.telegram.org
   - בחר "API Development Tools"
   - צור אפליקציה חדשה והעתק את `api_id` ו-`api_hash`

2. **Chat ID** (איפה לשלוח את הקבצים):
   - `me` = "Saved Messages" שלך
   - `@username` = משתמש אחר
   - `-1001234567890` = ערוץ/קבוצה (אפשר לקבל את ה-ID דרך `@userinfobot`)

3. **בחר מצב:**
   - **בוט:** פתח בוט אצל @BotFather, קבל token. פשוט אבל מוגבל ל-50MB לקובץ.
   - **חשבון משתמש:** צריך טלפון. הטלגרם ישלח לך קוד באפליקציה בלוגין הראשון.
     מאפשר עד 2GB (חשבון רגיל) או 4GB (Premium) לקובץ.

## הרצה

1. הרץ `python app.py`
2. בלשונית "הגדרות" — מלא את כל השדות ולחץ "שמור הגדרות"
3. לחץ "התחבר ל-Emby ↓" — אם הצליח, תועבר ללשונית "עיון ובחירה"
4. בעץ הספריות, לחץ פעמיים על ספריה/סדרה כדי לפתוח אותה
5. **בחירה:**
   - לסרט/פרק בודד: סמן ולחץ "הוסף לתור ←"
   - לסדרה שלמה: סמן את שורת הסדרה ולחץ "הוסף סדרה שלמה"
6. עבור ללשונית "תור" ולחץ "▶ התחל"
7. בלוגין הראשון של Pyrogram תקבל הודעה בטלגרם עם קוד אימות, הכנס אותו בטרמינל

## פלואו של פריט בודד

```
PlaybackInfo → DirectStreamUrl
    ↓
הורדה מ-Emby ל-~/downloads/file.mp4   (פרוגרס בלייב)
    ↓
העלאה לטלגרם דרך Pyrogram             (פרוגרס בלייב)
    ↓
מחיקה מהדיסק
    ↓
הפריט הבא בתור
```

## הערות

- **גודל קבצים:** S13E48 של הישרדות ישראל הוא 2.4GB — דורש Premium (4GB) או פיצול.
- **שמירת קונפיג:** `~/.emby_telegram_pipeline/config.json` (חוזרת כברירת מחדל).
- **קבצי session של Pyrogram:** `~/.emby_telegram_pipeline/sessions/` (לוגין נשמר).
- **תיקיית הורדה:** `~/.emby_telegram_pipeline/downloads/` (זמני, נמחק אחרי כל פריט).

## פתרון בעיות

| בעיה | מה לבדוק |
|------|-----------|
| "התחברות נכשלה" | בדוק base URL, שם משתמש וסיסמה |
| 403 בהורדה | Cloudflare — ייתכן שצריך לעדכן cloudscraper: `pip install -U cloudscraper` |
| Pyrogram לא נטען | `pip install -U pyrogram tgcrypto` |
| העלאה נכשלה "FILE_TOO_BIG" | קובץ מעל 2GB — צריך Premium או בוט |
| לוגין Pyrogram נתקע | בדוק את הטרמינל — הוא מבקש קוד אימות |
